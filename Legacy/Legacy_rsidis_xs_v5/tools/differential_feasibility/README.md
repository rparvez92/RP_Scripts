# Archived differential SIDIS feasibility workflow

These tools contain the event-binned `z`, `pt2`, and `phipq` occupancy,
migration, response-matrix, and one-dimensional extraction machinery developed
before the analysis returned to setting-integrated physics overviews. They are
preserved for future multidimensional work but are not part of the active
`rsidis_xs_v5` run sequence.

The scripts retain their original active-tree imports and output defaults and
may require path adjustments before reuse from this archive location.
